# Contra

Браузерный прототип тактического шутера на Three.js. Одна комната на десять участников; незанятые места заполняют боты. Телефон и компьютер подключаются к одному серверу. Локальная тренировка запускается в Web Worker и не требует готового сервера.

## Что работает

- 5 на 5, стрельба с серверной проверкой попаданий и видимости, здоровье, перезарядка, возрождение в тренировке.
- Закладка на A/B, таймер, обезвреживание, счёт и смена раундов.
- Recast Navigation по реальной геометрии Sandstone, капсула персонажа высотой1,82м, стены, ступени, гравитация и прыжок.
- Клавиатура/мышь, сенсорный джойстик и кнопки, интерактивный просмотр четырёх моделей.
- Два исходных персонажа: сохранены одежда, текстуры и силуэт. У covered устранены четыре наложенных тела. Настоящая анимация ходьбы из исходников отсутствовала; движение ног сейчас процедурное.

## Запуск

Node.js22+ и pnpm11.25:

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Открыть http://localhost:8766. Сервер использует `PORT` и слушает `0.0.0.0`. `pnpm test` проверяет физику, серверное управление двумя WebSocket клиентами и бой ботов на настоящей карте.

## Управление

WASD — движение, мышь — обзор, ЛКМ — огонь, R — перезарядка, E — удерживать для бомбы, пробел — прыжок, Esc — меню. На телефоне слева движение, справа обзор и кнопки действий.

## Размещение

Целевой сайт: https://contra-3d.onrender.com. Сборка статики: `pnpm install --frozen-lockfile && pnpm build`, каталог `dist/web`. Отдельный Node Web Service запускает `node server.mjs`; переменная сборки фронтенда `CONTRA_WEBSOCKET` задаёт его `wss://…/ws`. Без неё локальный сервер использует WebSocket того же адреса. Бесплатный сервер Render засыпает после простоя; локальная тренировка остаётся доступна.

## Модели и производительность

Пользователь предоставил GLB/ZIP; подготовка выполнена в Blender5.2.3 и glTF-Transform. Исходные файлы и .blend хранятся локально на F:, в Git опубликованы оптимизированные игровые GLB. Сжатие Meshopt, WebP, текстуры до1024px, общие текстуры между копиями персонажей. Полигональные детали сохранены. Карта Sandstone уменьшена с32,6MiB до4,74MiB; вся четвёрка моделей занимает11,81MiB.

Это прототип. Модели оружия пока процедурные; нет покупок, гранат, матчмейкинга и полноценного античита. Результаты прежнего сравнения пяти движков относятся к более простой тестовой сцене и не являются FPS этой версии.

Для нового замера: `/?benchmark=1&seconds=60` на локальном сервере, окно на переднем плане. Есть5секунд прогрева, измерение реальных интервалов кадров, средний FPS и1%low. Фоновые кадры учитываются как невалидные; результат сохраняется локально в `art/benchmarks`. Это проверка текущего устройства, не гарантия FPS на телефонах.

Технические источники: [Three.js](https://threejs.org/docs/), [Recast Navigation](https://github.com/isaac-mason/recast-navigation-js), [Render Free](https://render.com/docs/free), [Render WebSockets](https://render.com/docs/websocket).
