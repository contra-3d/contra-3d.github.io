# Contra

Согласованное направление: браузерный тактический шутер, основа Three.js, серверная логика отдельно от отрисовки. Подходы Babylon.js и Unity используются в организации игровых систем; три рендерера одновременно не запускаются.

Присланные GLB и карты улучшаются с сохранением внешности. Приоритет: корректные материалы и нормали, устранение дубликатов, правильный масштаб, коллизии и проходимость. Исходники сохранены в ../assets/incoming.

Текущий этап: подготовка моделей и изображений для оценки владельцем. Затем интеграция в игру и проверка производительности новой графики. Результаты старого сравнительного прототипа не выдаются за FPS новых моделей.

Размещение: Render, только бесплатный тип сервиса. Для публикации требуется подключённый аккаунт Render. Бесплатный сервер может засыпать после простоя; платный тариф не подключается.
