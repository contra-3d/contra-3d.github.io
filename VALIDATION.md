Четыре автоматические проверки прошли: капсула и земля; фильтрация некорректного управления; два клиента WebSocket в одной комнате и возврат бота после выхода;240секунд боя десяти ботов на настоящей Sandstone с попаданиями, убийствами, закладкой на A и B, завершением бомбы. ## Память сервера

В бесплатной среде Render исходный Octree достигал лимита256MiB JS heap при загрузке карты. Он заменён упакованным MeshBVH, который хранит большие треугольники земли без многократного дублирования. После изменения все4проверки, включая240секунд боя, повторно прошли с принудительным лимитом192MiB JS heap (`node --max-old-space-size=192 --test tests/game.test.mjs`).

Реальный бесплатный Node-сервер Render после загрузки карты:87MiB RSS,14MiB JS heap. Внешняя проверка WSS прошла:два клиента,10слотов,2человека и8ботов,общая комната contra. Скрипт проверки:tools/check-deployment.mjs.

Для занятого ранее статического сайта Render после смены repo продолжал клонировать прежний репозиторий. Подготовлена отдельная ветка contra-render-mirror с теми же коммитами в обоих репозиториях. Основные ветки прежних игр не изменялись. Канонический код Contra остаётся в contra-3d/contra-3d.github.io; ветка нужна для совместимости существующей привязки Render.
